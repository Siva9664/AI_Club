# Contributing to AI Club Frontend

## Getting Started
```bash
npm install
npm run dev
```

- **Branching model** – `main` (stable) and `develop` (integration). Feature work happens in short‑lived branches.
- **Code style** – ESLint + Prettier (run `npm run lint` and `npm run format`).
- **Commit messages** – use conventional commits, e.g. `feat: …`, `fix: …`, `chore: …`.
- **Pull Requests** – require at least one approving review from a code owner (see `CODEOWNERS`).
- **Testing** – run `npm run typecheck` and `npm run lint` before pushing.
