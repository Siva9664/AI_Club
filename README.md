# AI Club Frontend

## Project Overview
A modern React + TypeScript + Vite front‑end for the AI Club. The repo is organized by **feature ownership** to enable parallel work without merge conflicts.

## Setup
```bash
# Install dependencies
npm install

# Run the development server
npm run dev
```

## Available npm scripts
| Script | Description |
|--------|-------------|
| `dev` | Starts Vite dev server |
| `build` | Produces a production build |
| `lint` | Runs ESLint on `src/` |
| `format` | Formats code with Prettier |
| `typecheck` | Runs `tsc --noEmit` |
